Knowledge Graph Architecture

Neo4j Graph Topology & Schema

The cinema archive is ingested into an Aura database with unique movies, actors, directors, genres, and directed relationships.

Schema Definition

(:Person {name}) -[:DIRECTED]-> (:Movie {title, releaseYear, origin, wikiPage, plot})
(:Person {name}) -[:ACTED_IN]-> (:Movie {title, releaseYear, origin, wikiPage, plot})
(:Movie {title, releaseYear, origin, wikiPage, plot}) -[:HAS_GENRE]-> (:Genre {name})

Note: People are unified under the :Person label rather than distinct Actor/Director labels, allowing multi-role cinema professionals to be modeled accurately.

Sample Cypher Query

MATCH (m:Movie {title: "Inception"})<-[:DIRECTED]-(d:Person)
MATCH (m)-[:HAS_GENRE]->(g:Genre)
MATCH (m)<-[:ACTED_IN]-(p:Person)
RETURN m.title, d.name AS director, collect(g.name) AS genres, collect(p.name)[..5] AS cast;

Developer Endpoints

API & WebSocket Reference

FastAPI backend provides RESTful endpoints for telemetry, movie discovery, and real-time WebSocket communication.

Real-Time WebSocket: /ws/chat

Connect over WebSocket to receive multi-stage progress events followed by the final curated payload:

// Connect to WebSocket
const ws = new WebSocket("ws://localhost:8000/ws/chat");
ws.send(JSON.stringify({ query: "Films similar to Inception" }));

// Incoming Status Events:
// { type: "phase", phase: 1, text: "Searching the movie archive..." }
// { type: "phase", phase: 2, text: "Connecting stories and relationships..." }
// ...
// { type: "complete", answer: "...", movies: [...], sources: [...] }

REST Endpoints

GET /api/stats Returns Neo4j count, Pinecone vector count, and database health
GET /api/movies?limit=18 Retrieves catalog of featured movies for discovery mode
GET /api/movies/{title} Fetches deep movie metadata, cast, director, and plot synopsis
GET /api/graph?limit=150 Returns node-link graph data for D3 force simulation
POST /api/chat HTTP fallback endpoint returning synchronous research answers
